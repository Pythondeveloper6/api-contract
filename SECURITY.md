# Security Policy

api-contract is alpha software, developed in the open at
https://github.com/Pythondeveloper6/api-contract.

## Supported versions

| Version | Supported |
| ------- | --------- |
| 0.1.x   | Yes       |

## Reporting a vulnerability

Please report vulnerabilities privately, either by email to
pythondeveloper6@gmail.com or through GitHub's private vulnerability reporting
(the repository's **Security** tab, then **Report a vulnerability**). Do not
open a public issue or pull request for a security problem. Include the
affected version, steps to reproduce, and the impact you observed. You can
expect an acknowledgement as soon as possible; fixes ship in the next 0.1.x
release.

Note that `api-contract` imports your application to generate its schema, so
it runs your project's code with your permissions. Run it only on code you
trust, as you would run your test suite.
